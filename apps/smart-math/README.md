# 똑똑 연산 (Smart Math)

초1 ~ 고3 학생이 각자 태블릿에서 쓰는 **연산 학습 웹앱**입니다. 파일은 `index.html` 하나뿐입니다.

## 실행

- 브라우저로 `index.html`을 열면 됩니다. 빌드 과정은 없습니다.
- 여러 기기에서 쓰려면 아무 정적 호스팅(GitHub Pages, Netlify, Vercel 등)에 올리면 됩니다.
- 학생별 개인 링크: `index.html?user=<학생ID>` (프로필을 만들면 링크와 QR 코드가 나옵니다)

Tailwind, KaTeX, Google Fonts, QR 생성기는 CDN에서 불러오므로 **처음 열 때는 인터넷 연결이 필요**합니다.

## 기능

| 영역 | 내용 |
| --- | --- |
| 문제 뱅크 | 12개 학년, 48개 단원 × 난이도 하/중/상. 모든 문제는 무작위로 생성됩니다. 초등(사칙연산, 분수, 소수, 약수·배수, 혼합 계산, 비율), 중등(정수, 방정식, 부등식, 연립방정식, 일차함수, 지수법칙, 제곱근, 인수분해, 이차방정식·이차함수), 고등(다항식, 나머지정리, 복소수, 근과 계수, 순열·조합, 지수·로그, 삼각함수, 수열, 극한, 미분, 적분, 급수, 여러 가지 미분법, 확률, 확률분포)을 다룹니다. |
| 펜 필기 | 연습장 캔버스(색 3가지, 지우개, 되돌리기)와 답안 캔버스가 있습니다. Pointer Events로 필압을 반영하고, 펜 전용 모드에서는 손바닥 터치를 무시합니다. |
| 손글씨 인식 | 외부 API 없이 브라우저 안에서 인식합니다. 획을 글자 단위로 나누고, 16×16 특징 벡터와 KNN(코사인 유사도)으로 분류합니다. 여기에 닫힌 고리(구멍) 분석과 `- . , /` 모양 규칙을 더했습니다. 인식할 수 있는 문자는 `0-9 - . , /` 입니다. 대분수는 `1 1/2`처럼 띄어 쓰거나(키패드 "띄우기"), 자연수 옆에 세로 분수(분자·막대·분모)로 쓰면 됩니다. 인식된 글자를 누르면 다음 후보로 바뀝니다. |
| 내 글씨 학습 | 정답을 제출할 때 학생의 글씨를 개인 템플릿으로 저장합니다. "내 글씨 익히기" 메뉴에서 따로 학습시킬 수도 있습니다. |
| 채점·피드백 | 제출하면 바로 O/X로 채점합니다. 틀리면 먼저 그 오답이 어떤 실수에서 나오는지 짚어 줍니다(단원별 함정 오답 목록 + 부호·자릿값·역수·순서 같은 일반 진단). 그다음 핵심 개념 힌트와 단계별 풀이를 차례로 보여 주고, 한 번 더 도전할 수 있습니다. |
| 멀티 유저 | 이름, 학년, 캐릭터로 프로필을 만듭니다. `?user=` 링크로 들어오면 그 학생의 공간이 바로 열리고, 한 기기에서 여러 학생이 전환하며 쓸 수 있습니다. |
| 기록·루틴 | 오늘의 연산(학년 단원 혼합, 난이도 자동 조절, 오답 복습 포함), 하루 목표, 연속 학습 일수(최고 기록 포함), 이번 주 도장, 최근 20주 잔디밭, 단원별 정답률, 오답 노트(해결 스티커, 비슷한 문제 풀기) |
| 저장소 | 기본은 LocalStorage입니다. 설정에서 Supabase를 연결하면 로컬에 먼저 저장하고 클라우드로 동기화합니다. JSON 백업·복원도 됩니다. |

## Supabase 연동 (선택)

LocalStorage 기록은 그 기기의 브라우저에만 남습니다. 같은 링크로 **다른 기기**에서도 기록을 이어 쓰려면 다음과 같이 설정합니다.

```sql
create table if not exists public.sm_profiles (
  id text primary key,
  name text not null,
  data jsonb not null,
  updated_at timestamptz not null default now()
);
alter table public.sm_profiles enable row level security;
-- 데모용 정책입니다. 실제 서비스에서는 Supabase Auth + auth.uid() 기반 정책을 쓰세요.
create policy "sm demo rw" on public.sm_profiles for all to anon using (true) with check (true);
```

앱의 **설정 → 클라우드 동기화**에 Project URL과 anon key를 넣으면 연결됩니다.

> ⚠️ 위 데모 정책을 쓰면 anon key를 가진 누구나 모든 학생 기록을 읽고 쓸 수 있습니다. 가정이나 교실 안에서만 쓰세요.

## 코드 구조 (`index.html` 내부)

1. 수학 유틸 (분수 클래스, 다항식·세로셈 풀이 도우미)
2. 문제 뱅크: `U(학년, id, 이름, 설명, gen(d))`. 생성기는 `{prompt, expr, ans, type, hint, steps, traps}`를 반환합니다.
3. 채점 엔진과 오답 진단
4. 저장소 어댑터: `LocalStore` / `SupabaseStore` / `DB`(하이브리드)
5. 사용자 모델과 통계 (스트릭, 잔디밭, 단원 레벨)
6. 손글씨 인식기 `HW`
7. 펜 캔버스 `InkPad`
8. 이후: 화면(로그인, 홈, 단원 선택, 풀이, 결과, 오답 노트, 설정)

새 단원을 추가하려면 2번 섹션에 `U(...)`를 하나 더 쓰면 됩니다.
